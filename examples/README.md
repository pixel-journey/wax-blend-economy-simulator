# Examples

This folder contains production-ready, reusable component examples for modeling the economics of Atomic Blends on WAX.

## Shared Types

See `types.ts` for common interfaces used across the examples.

## Available Components

| File                    | Description                                           | Recommended Use Case                  |
|-------------------------|-------------------------------------------------------|---------------------------------------|
| `EconomicVisualizer.tsx`   | Visual display of key economic metrics                | Quick overview of cost vs value       |
| `ParameterControls.tsx`    | Reusable controls for simulation parameters           | Interactive input handling            |
| `ScenarioComparison.tsx`   | Side-by-side comparison of different scenarios        | Decision making and planning          |
| `InsightsPanel.tsx`        | Actionable insights and recommendations               | Turning data into guidance            |
| `demo.tsx`                 | Full composition example                              | Seeing how everything works together  |

## How to Use

1. Copy the components you need.
2. Adapt styling to your design system.
3. Connect simulation logic to your own data sources if needed.
4. Use shared types from `types.ts` for consistency.

These examples follow strict TypeScript and modern React patterns.
